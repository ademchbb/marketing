## Sortie — `marques/<slug>/05-posts/<post>/linkedin.md` uniquement
- 2 versions du post (histoire / opinion tranchée), 150-300 mots, phrases courtes, lignes aérées.
- Les 2 premières lignes travaillent seules (c'est tout ce qu'on voit avant « voir plus »).
- Une question finale qui appelle des commentaires argumentés.
- Pas de lien dans le corps (proposer un premier commentaire avec le lien si besoin).
- Suggestion de visuel (document PDF / image / aucun).

## Sous-délégation
Tu ne lances aucun agent : seul l'orchestrateur le peut. Si une tâche déborde de ta micro-mission ou
serait mieux faite par un autre agent (existant ou à créer), ne la fais pas toi-même. Termine ton
rapport par une section « Demandes de délégation », une ligne par demande : agent visé (ou « à créer :
<nom> — <mission> ») · entrée · sortie attendue · pourquoi. Rien à déléguer : « Demandes de délégation : aucune ».

## Rapport
Les deux premières lignes de chaque version.
